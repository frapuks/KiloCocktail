# Recette manuelle sur un vrai iPad

Maquette de référence (v5) : https://claude.ai/artifact/4CpJ7k3LCPJA8EAUhnfUwg

## Installation

- [ ] Ouvrir l'URL de l'appli dans Safari sur l'iPad.
- [ ] « Ajouter à l'écran d'accueil », puis lancer l'appli depuis l'icône (plein écran, sans barre Safari).
- [ ] Se connecter avec le compte du barman.
- [ ] Saisir le catalogue de cocktails (un cocktail par version : avec ou sans alcool, homonymes possibles).

## Soirée simulée en mode avion

- [ ] Activer le mode avion sur l'iPad.
- [ ] Créer une presta, puis compter plusieurs taps sur plusieurs cocktails.
- [ ] Utiliser le « − » (cumul « −N » visible, bouton inactif à 0).
- [ ] Modifier la presta (ajouter une ligne, retirer une ligne comptée).
- [ ] Fermer complètement l'appli, puis la rouvrir : les comptes sont toujours là.
- [ ] Terminer la presta, consulter les résultats.

## Retour du réseau

- [ ] Désactiver le mode avion.
- [ ] Vérifier que tout est arrivé : se connecter depuis un téléphone et retrouver la presta, ses totaux et ses résultats.

## Contrôle visuel (comparer à la maquette v5)

- [ ] Paysage : écran de comptage (cartes en deux colonnes, bandes avec / sans alcool, couleurs, polices).
- [ ] Paysage : accueil, cocktails, résultats, formulaire de presta.
- [ ] Portrait : écran de comptage (une carte par rangée, noms longs lisibles sans débordement).
- [ ] Portrait : accueil, cocktails, résultats, formulaire de presta.
- [ ] Cumul « +N » / « −N » visible environ 1,3 s après le dernier tap, sans retard perceptible du +1.
- [ ] Aucun zoom, sélection de texte ni menu contextuel lors de taps rapides.

## Défilement

- [ ] Portrait sur l'iPad : faire défiler la liste des cartes en partant d'une carte ne compte aucun verre (aucun total ne bouge, aucun « +1 » ne reste affiché).
- [ ] Sur le téléphone, faire défiler la liste en partant d'une carte ne compte aucun verre.
